This version uses a single, static CSS gradient for the entire page background. There is no more JavaScript swapping the styles when you scroll.

The effect is achieved by defining multiple "color stops" in the `linear-gradient` function. This allows us to have the gold at the top, fade to a long black section in the middle, and then fade back to gold at the very bottom of the page content.

The floating particles remain fixed, creating a nice parallax effect as you scroll through the content.
